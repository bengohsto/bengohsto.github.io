# Benjamin Goh: academic website

Plain HTML/CSS site served by GitHub Pages. No build step.

- Edit a page: open the `.html` file, change the text, commit, push. The live site updates in about a minute.
- Styles: `assets/style.css`. Photo: `assets/profile.jpg`.
- The nav menu is repeated at the top of each page; if you add a page, add its link to all five.
